# Mosaik³LAB – Installer-Pakete

Freigegebene Versionen von **Mosaik³LAB**, dem 3D-Druck-Katalog der Mosaikschule. Hier liegen nur die fertigen Pakete,
kein Quellcode. Jede Version ist vor der Veröffentlichung auf Windows, Linux und Raspberry Pi OS getestet worden
(Neuinstallation, Update, Rückfall, Deinstallation).

**Neueste Version:** unter [Releases](../../releases/latest).

| Datei | Für |
| --- | --- |
| `Mosaik3LAB-Installer-<version>-windows-x64.zip` | Windows 10/11 (64 Bit) |
| `Mosaik3LAB-Installer-<version>-linux-x64.tar.gz` | Linux-PC oder Server (Intel/AMD, 64 Bit) |
| `Mosaik3LAB-Installer-<version>-linux-arm64.tar.gz` | Raspberry Pi 4/5 mit Raspberry Pi OS 64 Bit |
| `SHA256SUMS.txt` | Prüfsummen der Pakete |

**Installieren:** Paket herunterladen und entpacken. Die Schritt-für-Schritt-Anleitung steht in der `README.txt` im Paket.

**Aktualisieren:** Ab Version 1.1.0 meldet der Server-Manager neue Versionen selbst und installiert sie per Knopfdruck,
mit Sicherung vorher und automatischem Rückfall bei Fehlern. Ältere Installationen aktualisiert man einmal mit dem
Paket von hier.
